# AI-Assistant Telegram Bot

![Aiogram](https://img.shields.io/badge/Aiogram-3.x-blue?style=for-the-badge)
![API](https://img.shields.io/badge/Model--API-Integration-green?style=for-the-badge)

A Telegram bot serving as an interface for interacting with an AI model via API. The project demonstrates proficiency in asynchronous requests and integrating third-party AI services into messaging platforms.

## 🛠 Key Features
* API Integration: Manages interaction with Google Gemini for text and image response generation.
* Asynchronous Engine: Utilizes the `aiogram` library to ensure high responsiveness and non-blocking performance.
* Context Handling: Supports text-based dialogue, image processing, and maintains conversation history for the model.
* Logging System: Implements comprehensive request and error tracking to ensure service stability.

## 📈 Technical Stack
* Language: Python
* Bot Framework: `aiogram`
* Integration: Google AI SDK
