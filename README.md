# AI-Assistant Telegram Bot

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Aiogram](https://img.shields.io/badge/Aiogram-3.x-blue?style=for-the-badge)
![API](https://img.shields.io/badge/Model--API-Integration-green?style=for-the-badge)

Телеграм-бот, выступающий в роли интерфейса для взаимодействия с нейросетевой моделью через API. Проект демонстрирует навыки работы с асинхронными запросами и интеграцию сторонних ИИ-сервисов в мессенджеры.

## 🛠 Функционал
* **Интеграция с API:** Организация взаимодействия с Google Gemini для генерации ответов.
* **Asynchronous Engine:** Использование асинхронной библиотеки aiogram для высокой отзывчивости бота.
* **Обработка контекста:** Поддержка текстового диалога, изображений и передача истории сообщений модели.
* **Система логирования:** Отслеживание запросов и ошибок для стабильной работы сервиса.

## 📈 Технический стек
* **Язык:** Python
* **Библиотека бота:** aiogram
* **Интеграция:** Google AI SDK
